# 演示素材说明

这些素材用于“语译”答辩时的方言、梗图和视频演示，可以直接在前端“方言 / 梗素材”区域点击体验。

## 文件

- `yue-00020.wav`：粤语短句“你好似瘦咗啲㖞！”
- `yue-01012.wav`：粤语长句“房间嘅窗帘唔够遮光，打电话叫前台送遮光帘，半个钟送到！”
- `yue-elder.wav`：长辈式粤语“后生仔，唔好成日挂住玩手机，早啲瞓啦。”
- `meme-yyds.png`：网络梗图“yyds”，底图来自 Picsum 公开照片
- `yue-00020.mp4`：Big Buck Bunny 公开视频底片 + 粤语音频，用于演示视频输入
